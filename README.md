# Польовий Модуль — V19.15.6 Burst Recoil Logic Fix

Версія на базі V19.15.5.

## Що виправлено

Виправлено фактичний розрахунок і відображення прогресивної віддачі черги.

У V19.15.5 після кількох черг підряд могло з’явитися:

```text
3-я черга, -4
4-а черга, -6
```

Це неправильно.

## Правильна логіка

```text
1-а черга: -2
2-а черга: -4
3-я черга: -6
4-а черга: -8
```

Якщо ціль в укритті:

```text
1-а черга по укриттю: -2 + -1 = -3
2-а черга по укриттю: -4 + -1 = -5
3-я черга по укриттю: -6 + -1 = -7
4-а черга по укриттю: -8 + -1 = -9
```

## Як виправлено

Додано єдине джерело правди:

```text
burstRecoilInfoForShooter()
```

Тепер і розрахунок, і текст беруть номер черги та штраф із одного місця.

## Що не змінювалося

Не змінювалися:

- модель шкоди;
- крит;
- укриття як -1;
- скидання віддачі після 1/2 патронів;
- Firebase;
- бойова панель;
- картки ворогів;
- шаблони ворогів.
