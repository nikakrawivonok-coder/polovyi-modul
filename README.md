# Польовий Модуль — V18.11 GM Active Player Links Single File

Ця версія зроблена на основі стабільної V18.10.

## Що додано

### 1. У Майстра показується тільки активний гравець

У вкладці:

Майстер → Гравці

тепер повна форма параметрів показується тільки для активного персонажа.

Щоб побачити іншого персонажа, треба натиснути на його кнопку зверху, наприклад:

- Лис
- Сірий
- Патріція

Це прибирає зайвий довгий скрол і робить керування Майстра з телефону зручнішим.

### 2. Окремі посилання для кожного гравця

У вкладці:

Майстер → Кімната / доступ

додано блок:

- Посилання на гравців

Там з’являється окрема кнопка для кожного персонажа, наприклад:

- Посилання: Лис
- Посилання: Сірий

Кожна кнопка копіює URL саме для цього персонажа.

## Що не змінювалося

Не змінювалися:

- Firebase;
- вороги;
- Оточення;
- бойова логіка;
- зброя;
- клин;
- реакції ворогів;
- відновлення базової сцени.
