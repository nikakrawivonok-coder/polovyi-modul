# Польовий Модуль — V19.11.3 Combat Bar Actor Target Separation

Версія на основі V19.11.2.

## Головна зміна

Бойова панель Майстра тепер розділяє:

- хто зараз ходить;
- хто є ціллю.

## Що додано

У панелі є два режими:

- `Хід`
- `Ціль`

Як це працює:

- режим `Хід` + тап по учаснику → цей учасник стає активним ходом;
- режим `Ціль` + тап по учаснику → цей учасник стає ціллю;
- ціллю може бути гравець або ворог;
- активним ходом може бути гравець або ворог.

## Візуальне виправлення

Панель піднята вище, щоб не перекривати нижні кнопки:

- `Стан`
- `Оточення`
- `Вороги`
- `Журнал`
- `Майстер`

## Що не змінювалося

Не змінювалися:

- бойова математика;
- журнал;
- player-посилання;
- Firebase;
- шаблони ворогів;
- інтерфейс гравця.
