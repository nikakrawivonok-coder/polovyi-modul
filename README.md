# Польовий Модуль — V19.17.3 Damage Roll Line

Точкова версія на базі V19.17.2.

## Що додано

### Рядок випаду шкоди у короткому бойовому підсумку

Після рядка з d20-кидками у вкладці `Стан` тепер показується окремий рядок шкоди, якщо атака влучила:

```text
Лис: Черга → Автоматник
🎲 5, 11, 16 → 3, 9, 14
Випало: 4 на 1d4
1 влуч., шкода 4. Автоматник: поранений.
```

Цей рядок бачать і Майстер, і гравець. Він не відкриває точні HP ворога для гравця, але додає прозорість і азарт: видно не лише підсумкову шкоду, а й реальний результат кубика шкоди.

Для кількох влучань рядок масштабується, наприклад:

```text
Випало: 3, 4 на 2d4
```

Для критичної шкоди додається окрема частина:

```text
Випало: 3 на 1d4 + 4 на крит. 1d4
```

## Що збережено з V19.17.2

- Майстер бачить точні HP ворогів у своєму `lastBriefGm`.
- Гравець бачить тільки публічний стан ворога у `lastBriefPublic`.
- Legacy/cached `lastBrief` із точними HP ворога додатково очищується на боці гравця.

## Що не змінювалося

Не змінювалися:

- бойова математика;
- правила 1 / 2 / 3 патрони;
- віддача черги;
- формула шкоди;
- критична шкода;
- шаблони ворогів;
- Firebase-схема як структура даних;
- журнал як основна система записів.
