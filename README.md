# Польовий Модуль — V19.15 Combat Clarity / GM Enemy Ammo Privacy

Версія на базі V19.14.2.

## Що змінено

Це версія прозорості бою й приватності інформації Майстра.

## 1. Гравець не бачить набої ворогів

У публічних бойових результатах приховано кількість патронів ворога.

Майстер і надалі бачить цю інформацію в GM-журналі.

Ціль:

```text
гравець бачить наслідок атаки
Майстер бачить ресурс ворога
```

## 2. Бойовий результат став прозорішим

У нижньому блоці `Стан` після пострілу додано пояснення релевантних модифікаторів:

```text
Віддача черги
штраф черги
укриття цілі: додатковий -1
розкриття -1 / сильне розкриття -2
бонус шкоди застосовано один раз
```

## 3. Математика не змінювалася

Не змінювалися:

- точність;
- шкода;
- черга;
- броня;
- крит;
- Firebase;
- структура кімнати;
- бойова панель;
- шаблони ворогів.
