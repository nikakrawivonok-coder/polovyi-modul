# Польовий Модуль — V19.10 Enemy Attack MVP

Версія на основі стабільної V19.9.

## Головна зміна

Додано перший робочий MVP атак ворогів по гравцях.

У вкладці **Майстер → Бойовий режим** вороги можуть атакувати обрану ціль-гравця.

## Люди зі зброєю

Для людей лишається логіка:

- Точний постріл: `1d20 +2`, 1 набій;
- Бойовий постріл: `2d20 +0`, 2 набої;
- Черга: `3d20 -2`, 3 набої;
- Обріз: окрема близька атака.

## Мутанти

Для мутантів кнопки показують:

- Обережна: `1d20 +2`;
- Стандартна: `2d20 +0`;
- Люта: `3d20 -2`.

Мутанти не витрачають набої. Люта атака додає ворогу стан `розкритий`, тобто атаки по ньому мають бути легшими для Майстра до наступного ходу.

## Баланс мутантів

Перший MVP уже враховує головний принцип:

- слабкі мутанти можуть завдавати малу шкоду за кожне влучання;
- Псевдособака не множить `d4+1` за кожне влучання, а дає шкоду + ефекти;
- Кровосос не б’є `3d6`, а обмежує burst;
- Контролер має бити контролем/Втомою, а не прямою шкодою.

## Toast

Результат атаки ворога показується у спливаючому повідомленні на 8 секунд.

## Що не змінювалося

Не змінювалися:

- Firebase-архітектура;
- постріли гравців;
- Оточення;
- інтерфейс гравця;
- шаблони ворогів;
- Command Core.
