# Польовий Модуль — V19.14 Progressive Recoil & 2-Shot Exposure

Версія на базі V19.13.1.

## Що змінено

Оновлено фінальну бойову модель режимів стрільби.

### 1 патрон — точний постріл

```text
1d20 +2
1 набій
без дебафу
```

### 2 патрони — бойовий постріл

Було:

```text
2d20 +0
```

Стало:

```text
2d20 -1
```

Додано правило:

```text
якщо 0 влучань — стрілець розкрився:
Захист -1 / атаки по ньому +1 до його наступного ходу
```

### 3 патрони — черга

Черга тепер має прогресивну віддачу:

```text
1-ша черга підряд: 3d20 -2
2-га черга підряд: 3d20 -4
3-тя черга підряд: 3d20 -6
4-та черга підряд: 3d20 -8
і так далі
```

Постріл 1 або 2 патронами скидає віддачу.

Після кожної черги стрілець розкривається:

```text
Захист -1 до його наступного ходу
```

## До кого застосовується

Правило застосовується до:

- гравців;
- ворогів-людей зі зброєю.

Мутантські атаки не змінювалися.

## Що не змінювалося

Не змінювалися:

- формули шкоди зброї;
- критична шкода;
- Firebase-структура;
- шаблон Автоматника, крім текстового опису атак;
- інтерфейс бойової панелі;
- нижній формат результату пострілу;
- popup, окрім появи тексту про розкриття в результаті.
