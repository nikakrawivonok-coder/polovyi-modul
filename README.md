# Польовий Модуль — V19.1 Compact GM Panel

Ця версія зроблена на основі стабільної V19 Modular Base.

## Що додано

### Компактна панель Майстра

У верхній частині вкладки «Майстер» додано компактну панель швидкого керування.

Вона показує:

- активного гравця;
- активного ворога / ціль;
- стан бою;
- HP активного гравця;
- набої активного гравця;
- стан активного ворога.

## Швидкі дії в панелі

Додані кнопки:

- Почати / Завершити бій;
- Наступний хід;
- Відновити сцену;
- Посилання гравця.

## Що не змінювалося

Не змінювалися:

- Firebase;
- вороги;
- Оточення;
- бойова логіка;
- зброя;
- клин;
- реакції ворогів;
- структура даних кімнати.

## Що перевірити

1. Відкрити вкладку «Майстер».
2. Перевірити, що зверху є «Панель Майстра».
3. Перемкнути активного гравця через панель.
4. Перемкнути активного ворога через панель.
5. Натиснути «Почати бій».
6. Натиснути «Наступний хід».
7. Натиснути «Посилання гравця».
8. Переконатися, що старі блоки Майстра нижче працюють як раніше.
