# Польовий Модуль — V5.2 Single File

Це аварійно-стабільна версія для GitHub Pages: весь додаток зібраний в один файл `index.html`.

## Чому так

Попередня версія відкривала HTML, але не запускала зовнішній `app.v5-1.js`. У цій версії немає зовнішніх `app`, `styles` і `sw` файлів — усе вбудовано прямо в `index.html`.

## Як встановити

1. Створи новий репозиторій або очисти старий.
2. Завантаж тільки:
   - `index.html`
   - `README.md`
3. Увімкни GitHub Pages з гілки `main`, папка `/root`.
4. Відкривай:

Майстер:
`https://твій-нік.github.io/репозиторій/?role=gm&room=zona01&v=52`

Гравець:
`https://твій-нік.github.io/репозиторій/?role=player&room=zona01&player=fox&v=52`

## Важливо

Тут вимкнено service worker, щоб старий кеш не заважав.
