# Польовий Модуль — V19.11.13 Combat Feedback Real Path Fix

Версія виправляє саме ті бойові шляхи, які реально використовує панель Майстра.

## Що було не так у V19.11.12

Було два реальні шляхи:

- `applyPlayerShotToEnemyFromPanel()` для `гравець → ворог`;
- `enemyAttack()` для `ворог → гравець`.

У V19.11.12 частина правок потрапила не в той шлях, тому:

- popup ворога міг лишатися перевантаженим;
- нижній блок `гравець → ворог` міг втратити частину потрібної інформації.

## Що виправлено

### 1. Popup ворог → гравець

Тепер popup атаки ворога використовує той самий короткий стиль, що й атака гравця:

- хто стріляє → ціль;
- кубик атаки;
- результат;
- коротко: влучання / шкода / HP / набої.

Детальна технічна інформація винесена в нижній static-блок.

### 2. Static-блок гравець → ворог

У нижньому блоці вкладки `Стан` для атаки гравця тепер є повна інформація:

- опис дії;
- кубик атаки;
- кидок атаки;
- підсумок;
- точність;
- ціль і захист;
- влучання / промах;
- шкода і формула;
- `🎲 Шкода зброї`;
- зброя / дистанція / стан;
- HP цілі;
- реакція ворога;
- ефекти ворога;
- набої стрільця.

### 3. Реакції та ефекти

Реакція ворога й ефекти ворога лишаються тільки для:

- `гравець → ворог`.

Для:

- `ворог → гравець`

вони не додаються автоматично.

## Що не змінювалося

Не змінювалися:

- логіка `Хід / Ціль`;
- розрахунок шкоди;
- крит;
- списання набоїв;
- Firebase;
- журнал;
- player-посилання;
- бойова панель.
