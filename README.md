# Польовий Модуль — V19.7 Compact Player Editor Sections

Версія на основі стабільної V19.6.

## Головна зміна

Вкладку **Майстер → Гравці** перероблено на компактний редактор із секціями.

## Секції

Тепер активний гравець редагується через блоки:

- Профіль;
- Бойові налаштування;
- Зброя;
- Характеристики;
- Інвентар.

## Що стало компактніше

Поля:

- HP;
- Макс. HP;
- Втома;
- Зараження;
- Набої;
- Броня;
- Захист;
- Макс. захист;

зібрані в одну секцію **Бойові налаштування**.

## Що додано у редактор

У секції **Зброя** є:

- зброя;
- дистанція: близько / середньо / далеко;
- стан зброї;
- клин.

## Що не змінювалося

Не змінювалися:

- Firebase;
- бойова математика;
- вороги;
- Оточення;
- інтерфейс гравця;
- Command Core.
