# Польовий Модуль — V21 Enemy System Restore Single File

V21 повертає систему ворогів на робочу базу V18.

## Що виправлено

### 1. Вороги взяті з робочої V18
Повернуто:
- нижню вкладку «Вороги»;
- нормальний список ворогів;
- відображення фото/іконки, назви і стану;
- додавання ворогів у Майстра;
- шаблони ворогів;
- синхронізацію ворогів через Firebase.

### 2. Додано розгортання деталей ворога
При натисканні на ворога під ним відкривається компактний блок з деталями:
- позиція;
- небезпека;
- поточна дія;
- HP;
- набої;
- мораль;
- захист.

### 3. Збережено корисні правки
Збережено:
- чистішу назву «Польовий Модуль» без декоративних символів;
- вирівнювання значків характеристик;
- toast кидків на 8 секунд;
- у Майстра показ форми тільки активного персонажа;
- блок «Посилання гравців».
