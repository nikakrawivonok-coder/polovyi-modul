## Що сталося у V18.12

Частина JavaScript-коду випадково потрапила прямо в HTML-сторінку, а не всередину `<script>`.
Через це браузер показував код як текст над інтерфейсом.

## Що зроблено у V18.12.1

V18.12.1 зроблена не на основі зламаної V18.12, а на основі стабільної V18.11.2.

Додано лише обережні стабілізаційні правки:

- safeSetText();
- safeSetHTML();
- safeCall();
- normalizeRoomDataLight();
- безпечні оновлення необов’язкових елементів;
- нормалізація старих Firebase-даних.
