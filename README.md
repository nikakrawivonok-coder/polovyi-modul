# Польовий Модуль — V19.5 Command Core + ROADMAP

Версія на основі стабільної V19.4.

## Що змінено

### 1. Прибрано дубльовані кнопки активного гравця

Прибрано кнопки:

- `+1 HP`
- `−1 HP`
- `−1 Втома`
- `+1 Втома`

Вони дублювали кнопки `− / +` вище і займали місце в Панелі Майстра.

### 2. Додано технічне ядро команд

В `app.js` додано функцію:

```js
doCommand(command)
```

Це центральний диспетчер команд для майбутніх систем:

- кнопок Майстра;
- шаблонів ворогів;
- шаблонів сцен;
- швидкого луту;
- приватних повідомлень;
- автоматизації правил;
- ШІ-помічника;
- голосових команд.

## Перші підтримані команди

- `setActivePlayer`
- `setTargetEnemy`
- `stepPlayerStat`
- `stepEnemyStat`
- `setEnemyField`
- `toggleEnemyEffect`
- `setEnemyQuickState`
- `addJournalLog`
- `addComplication`

## 3. Додано ROADMAP.md

Тепер у проєкті постійно є файл `ROADMAP.md`, який фіксує:

- стабільну точку;
- ціль проєкту;
- пріоритети;
- майбутні версії;
- правила розробки;
- що не можна ламати.

## Що не змінювалося

Не змінювалися:

- Firebase;
- бойова математика;
- зброя;
- клин;
- вороги;
- Оточення;
- інтерфейс гравця.
