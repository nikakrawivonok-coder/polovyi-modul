# Польовий Модуль — V6 Firebase Single File

Це перша онлайн-версія з Firebase Realtime Database.

## Як встановити

У новий або поточний чистий GitHub Pages репозиторій завантаж тільки:

- `index.html`
- `README.md`

## Посилання

Майстер:
`https://твій-нік.github.io/polovyi-modul/?role=gm&room=zona01&v=6`

Гравець:
`https://твій-нік.github.io/polovyi-modul/?role=player&room=zona01&player=fox&v=6`

## Що працює

- спільна кімната `rooms/{room}`;
- синхронізація стану гравця;
- синхронізація сцени;
- синхронізація ворогів;
- синхронізація інвентарю;
- спільний журнал;
- кидки гравця записуються в Firebase;
- майстерські зміни видно гравцям.

## Важливо

Firebase Rules зараз тестові й відкриті. Для регулярної гри треба додати ключ Майстра / пароль кімнати.
