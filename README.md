# Польовий Модуль — V19.15.5 Recoil Display Fix

Версія на базі V19.15.4.

## Що виправлено

Виправлено відображення віддачі черги.

Було можливо побачити некоректний підпис на кшталт:

```text
Віддача: 2-а черга, -2 до точності.
```

Це неправильно, бо друга черга підряд має давати `-4`.

## Правильна логіка

```text
1-а черга підряд: -2 до точності
2-а черга підряд: -4 до точності
3-я черга підряд: -6 до точності
4-а черга підряд: -8 до точності
```

Якщо ціль в укритті:

```text
1-а черга по укриттю: -2 віддача + -1 укриття = -3 разом
2-а черга по укриттю: -4 віддача + -1 укриття = -5 разом
3-я черга по укриттю: -6 віддача + -1 укриття = -7 разом
```

## Як тепер показується

Без укриття:

```text
Віддача: 2-а черга, -4 до точності.
```

З укриттям:

```text
Віддача: 2-а черга, -4 до точності.
Укриття: ще -1 до черги.
Разом: -5 до точності.
```
