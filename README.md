# Польовий Модуль — V14.1 Input Fix Single File

V14.1 виправляє втрату фокусу в полях введення.

## Що виправлено

У V14 під час введення тексту кожна літера запускала повний `render()`, через що поле перемальовувалося і втрачало фокус. У V14.1:

- текстові поля більше не перемальовують весь інтерфейс на кожну літеру;
- стан все одно зберігається у Firebase;
- при необхідному перемальовуванні фокус і позиція курсора відновлюються;
- кнопки й синхронізація V14 збережені.
