# Польовий Модуль — V22.1 Enemy Hotfix Single File

V22.1 відновлює ворогів на базі робочої V18 і переносить вибір цілі у вкладку «Вороги».

## Що виправлено

### 1. Вороги відновлені з робочої V18
Повернено стабільну систему:
- нижня вкладка «Вороги»;
- список ворогів;
- додавання ворогів у Майстра;
- шаблони ворогів;
- синхронізація ворогів через Firebase.

### 2. Прибрано окремий блок «Ціль пострілу»
На екрані «Стан» більше немає окремого блоку «Ціль пострілу».

### 3. Ціль обирається у вкладці «Вороги»
- перший тап по ворогу обирає його ціллю;
- повторний тап по вже обраному ворогу розгортає/згортає деталі.

### 4. Збережено інші корисні правки
- назва «Польовий Модуль» без декоративних символів;
- toast кидків тримається 8 секунд;
- у Майстра форма лише активного персонажа;
- блок «Посилання гравців».
