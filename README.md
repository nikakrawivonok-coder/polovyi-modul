# Польовий Модуль — V16 State Layout Refresh Single File

V16 прибирає верхній інформаційний блок зі шляху гри, показує захист у картці персонажа та покращує пропорції портрету.

## Що нового

### 1. Кімната / Роль / Персонаж / Синхронізація / Доступ
Блок більше не стоїть під назвою зверху.
Тепер він перенесений униз екрана «Стан», щоб не забирати корисний простір на старті.

### 2. Захист у характеристиках персонажа
У картці персонажа над «Здоров’я» додано компактний рядок:
- 🛡 Захист: поточне / максимальне

Наприклад:
- 12 / 12

У майстерському редагуванні для гравця є:
- Захист поточний
- Захист максимум
- Броня

### 3. Ширший блок портрета
Ліва панель портрета стала трохи ширшою.

### 4. Менше порожнечі над головою
Фігура сталкера збільшена й піднята, щоб зверху було менше порожнього простору.
