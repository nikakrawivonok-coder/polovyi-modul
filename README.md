# Польовий Модуль — V19.16 Enemy Tab Master Tools

Версія на базі V19.15.11.

## Головна ідея

Вкладка `Вороги` починає ставати робочим місцем Майстра, а не просто списком.

## Що додано

### 1. Майстерський блок шаблонів у вкладці Вороги

Для Майстра у вкладці `Вороги` є блок:

```text
Шаблони ворогів
```

Поки доданий один шаблон:

```text
Автоматник
```

З параметрами:

```text
Захист 11
HP 10
Набої 9
Броня 0
Втома 0
Зараження 0
АКС-74У
```

### 2. Лут шаблону

У шаблоні автоматника показується орієнтовний лут:

```text
залишок набоїв; 1d4 додаткових набої; ніж або саморобний клинок; дріб’язок 10–40
```

### 3. Картки ворогів стали рольовими

Для Майстра картка ворога показує:

```text
HP
набої
броню
втому
зараження
зброю
мораль
ефекти
лут
характеристики
швидкі кнопки стану
```

Для гравця картка ворога не показує точні HP, набої, мораль, лут і небезпеку.

### 4. Нижня вкладка Вороги лишається окремим місцем

`Стан` лишається чистим, а повні вороги — у вкладці `Вороги`.

- шкода;
- крит;
- журнал;
- Firebase-структура;
- бойова панель;
- вкладка Стан;
- видимі цілі.
