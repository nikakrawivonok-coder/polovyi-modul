# Польовий Модуль — V19.11.7 Combat Feedback Visibility Fix

Версія на основі стабільної логіки V19.11.6.

## Що виправлено

### 1. Бойова панель трохи піднята

Панель була майже правильно розташована, але трохи заходила на нижні кнопки.  
Тепер її піднято на кілька пікселів:

- було `bottom: 64px`;
- стало `bottom: 68px`.

### 2. Спливаюче повідомлення про кидок

Раніше toast/спливаюче повідомлення про постріл частково ховалося під бойовою панеллю.

Тепер:

- повідомлення підняте над бойовою панеллю;
- має більший `z-index`;
- має `max-height` і прокрутку, якщо текст довгий;
- показується приблизно 6 секунд.

### 3. Статичний результат у вкладці “Стан”

Результат пострілу тепер має лишатися внизу вкладки `Стан` не тільки для:

- гравець → ворог,

а й для:

- ворог → гравець.

У статичному блоці показується:

- хто стріляв;
- по кому;
- кидки;
- цільове число;
- влучання/промах;
- шкода;
- HP цілі;
- скільки набоїв лишилося у стрільця.

## Що не змінювалося

Не змінювалися:

- логіка шкоди;
- логіка Хід / Ціль;
- Firebase;
- журнал;
- player-посилання;
- шаблони ворогів.
