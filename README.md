# Польовий Модуль — V12 Campaign Presets Single File

V12 додає заготовки кампанії, тихі сцени після поразки та збереження/імпорт JSON.

## Що нового

### Кампанія / заготовки
- Бандитський блокпост
- Маршрут через аномалії
- Зниклий сталкер

Пак пригоди завантажує сцену, стартових ворогів, зачіпку і службову нотатку Майстра.

### Тихі сцени після поразки
- Пограбовані бандитами
- Викинуті аномалією
- Прокинулись у полоні
- Їх витягнув незнайомець

Тиха сцена змінює локацію, очищає ворогів, завершує бій і застосовує наслідки до гравців.

### Збереження кампанії
- Завантажити JSON кампанії
- Скопіювати JSON
- Імпорт кампанії
