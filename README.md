# Польовий Модуль — V19.13.1 Автоматник Balance & Stats Patch

Точкова правка на базі V19.13.

## Що змінено

Оновлено шаблон ворога `Автоматник`.

### Баланс для комфортнішої гри

Було:

```text
Захист: 12
HP: 12
Набої: 6
```

Стало:

```text
Захист: 11
HP: 10
Набої: 9
```

Логіка: гравці мають частіше влучати у ворога, а автоматник має бути небезпечним через зброю й поведінку, а не через надмірну живучість.

## Додано в шаблон ворога

Тепер автоматник має базові поля, аналогічні до гравця:

```text
Втома: 0
Зараження: 0
Броня: 0
Захист максимум: 11
Клин зброї: false
```

Характеристики:

```text
Витривалість: +1
Точність: +1
Вправність: +1
Сприйняття: +1
Інтуїція: 0
Харизма: -1
```

## Додано нормалізацію для всіх ворогів

Щоб майбутні шаблони були стабільнішими, для кожного ворога тепер безпечно проставляються поля:

```text
defenseMax
fatigue
infection
armor
stats
weaponJammed
```

Це не змінює бойову механіку, але готує систему до майбутніх ворогів, втоми, зараження, броні та характеристик.
