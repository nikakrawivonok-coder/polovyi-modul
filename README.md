# Польовий Модуль — V11 Multi-Player Control Single File

V11 додає нормальне керування кількома гравцями.

## Що нового

- Майстер може обирати активного персонажа.
- Активний персонаж використовується для:
  - поточного майстерського редагування;
  - інвентарю у вкладці Майстра;
  - видачі луту;
  - кастомних предметів.
- У блоці «Гравці» видно, хто активний.
- Для кожного гравця є кнопка «Обрати активним».
- Додавання нового гравця автоматично робить його активним.
- У блоці «Лут / знахідки» є вибір, кому видати лут.
