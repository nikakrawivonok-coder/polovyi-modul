# Польовий Модуль — V18 Targeted Actions Single File

V18 додає вибір цілі для пострілів гравця, розгортний інвентар, характеристики персонажа та покращене введення тексту.

## Що нового

### 1. Інвентар розгортається на вкладці «Стан»
Кнопка «Інвентар» більше не відкриває окрему вкладку.
Вона розгортає меню інвентарю прямо під швидкими діями.

### 2. Поля введення стали спокійнішими
Під час набору тексту модуль більше не відправляє зміну у Firebase на кожну літеру.
Дані зберігаються після завершення редагування поля.

### 3. Характеристики персонажа
У меню «Стан» додано:
- Витривалість
- Точність
- Вправність
- Сприйняття
- Інтуїція
- Харизма

Початково всі значення дорівнюють 0.

### 4. Вибір цілі пострілу
На вкладці «Стан» з’явився блок «Ціль пострілу».
Гравець обирає видимого ворога, після чого кнопки:
- Точно
- Нормально
- Черга

кидають кубики саме по цій цілі.

### 5. Автоматичні влучання по ворогах
Постріл гравця тепер:
- додає Точність персонажа;
- порівнює результат із Захистом ворога;
- визначає кількість влучань;
- знімає HP ворогу;
- оновлює стан ворога.

### 6. Спливаючі результати кидків
Після натискання дії результат одразу видно на екрані:
- назва дії;
- кубики;
- результат;
- характеристика, яка вплинула на кидок;
- зелений модифікатор для плюса;
- червоний для мінуса.
