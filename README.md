# Польовий Модуль — V18.2 Enemy Double Tap Details Single File

Ця версія зроблена на основі стабільної V18.1.

## Що додано

### Подвійний тап по ворогу

У вкладці «Вороги»:

- один тап по ворогу — обирає його ціллю пострілу;
- подвійний тап по ворогу — розгортає або згортає інформацію під цим ворогом.

## Деталі ворога

У розгорнутому блоці показується:

- стан;
- позиція;
- небезпека;
- що робить;
- HP;
- набої;
- мораль;
- захист.

## Що не змінювалося

Не змінювалися:

- додавання ворогів;
- шаблони ворогів;
- вкладка «Оточення»;
- Майстерська панель;
- Firebase-синхронізація;
- логіка пострілів;
- блок «Ціль пострілу» на вкладці «Стан».
