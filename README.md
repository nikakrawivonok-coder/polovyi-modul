# Польовий Модуль — V19.17 Enemy Template: Бандит з обрізом

Версія на базі стабільної V19.16.7.

## Що додано

### Другий шаблон ворога

У вкладці `Вороги` для Майстра тепер доступні два швидкі шаблони:

```text
Автоматник
Бандит з обрізом
```

`Бандит з обрізом` доданий як окрема картка шаблону за якістю ближче до `Автоматника`:

- роль: засідка, ближній тиск, небезпека у проходах;
- Захист: 12;
- HP: 8;
- Броня: 0;
- зброя: Обріз;
- набої: 3;
- поведінка: підпускає ближче, тримає короткий сектор, небезпечний біля дверей/машин/вузьких місць;
- слабкість: дальня дистанція й відкрита місцевість.

## Що бачить Майстер

Майстер бачить повну картку шаблону:

- HP;
- Захист;
- Броню;
- зброю;
- набої;
- характеристики;
- лут;
- атаки;
- слабкість.

Кнопка `+ Додати: Бандит з обрізом` додає нового ворога у поточну сцену.

## Що бачить гравець

Гравець, як і раніше, не бачить GM-інформацію ворога:

- точні HP;
- точні набої;
- мораль;
- лут;
- службові деталі шаблону.

## Що не змінювалося

Не змінювалися:

- бойова математика;
- правила 1 / 2 / 3 патрони;
- віддача черги;
- формула шкоди;
- критична шкода;
- Firebase-структура;
- журнал;
- лут як механіка передачі;
- вкладка `Стан`;
- видимі цілі.
