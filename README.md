# Польовий Модуль — V10 Combat Mode Single File

V10 додає бойовий режим для швидкого ведення перестрілки.

## Що нового

### Видимий для гравця блок «Бій»
- статус бою;
- раунд;
- активний хід;
- список учасників;
- остання бойова подія.

### Майстерський бойовий режим
- Почати бій;
- Наступний хід;
- Завершити бій;
- Перевірка моралі;
- швидка шкода ворогам: -1 HP / -3 HP;
- лікування ворога +1 HP;
- перемикання укриття;
- швидке вибуття ворога.

### Мораль
Кнопка «Перевірка моралі» кидає d20 і дає швидкий результат:
- тримаються;
- нервують і шукають укриття;
- ламаються або відступають.
