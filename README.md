# Польовий Модуль — V17 Action Panels Single File

V17 виправляє нюанси V16 і додає розгортні меню гравця.

## Що нового

### 1. Виправлення HP при редагуванні гравців
Числові поля більше не записують `0`, якщо поле тимчасово порожнє під час редагування.
Це мало прибрати ситуацію, коли виставляєш 8/15, а у стані показується 0/15.

### 2. Захист як поріг влучання
Захист тепер показується як окремий поріг:
- `🛡 Захист: 12`

Це не додаткове здоров’я. Ворог має зрівняти або перевищити це число на d20, щоб влучити.
Укриття підвищує поріг, броня зменшує шкоду.

### 3. Компактніший блок персонажа
- Прибрано світлий прямокутник за «Захист».
- Прибрано круговий фон під помаранчевим знаком зараження.
- Характеристики зроблені компактнішими.
- Портрет збільшений і підтягнутий, щоб було менше пустоти над головою.

### 4. Нова кнопка «Стан»
У порожній шостій клітинці швидких дій додано кнопку:
- `Стан`

Вона розгортає/згортає меню з:
- Захистом
- Бронею
- Укриттям
- Набоями
- HP / Втомою / Зараженням
- Активними ефектами

### 5. Кнопка «Оглянути» перейменована на «Дії»
Кнопка `Дії` розгортає додаткове меню:
- Оглянути
- Кинути болт
- Інтуїція
- Оглянути товариша
- Поштовх
- Прислухатись
