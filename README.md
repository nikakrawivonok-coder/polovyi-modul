# Польовий Модуль — V18.11.2 Player Links Real Fix Single File

Це hotfix до V18.11.1.

## Що виправлено

У V18.11.1 блок «Посилання на гравців» був створений, але список кнопок не промальовувався, бо функція рендеру не викликалася в основному render().

Також обробник кнопки посилався на допоміжні функції, яких у цій збірці не було.

У V18.11.2 виправлено обидві проблеми.

## Що тепер має бути

У вкладці:

Майстер → Кімната / доступ

під блоком «Посилання на гравців» мають відображатися всі персонажі кімнати:

- Скопіювати: Лис
- Скопіювати: Сірий
- Скопіювати: Патріція

Під кожною кнопкою також видно сам URL, щоб можна було перевірити, що там правильний `player=`.

## Що не змінювалося

Не змінювалися:

- Firebase;
- вороги;
- Оточення;
- бойова логіка;
- зброя;
- клин;
- реакції ворогів;
- відновлення базової сцени.
