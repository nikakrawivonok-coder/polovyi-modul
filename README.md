# Польовий Модуль — V19.15.3 Compact Combat Log

Версія на базі V19.15.2.

## Що змінено

Це UX-правка бойового тексту. Математика не змінювалася.

## Навіщо

V19.15 дала багато прозорості, але бойовий запис став занадто довгим для живої гри.

У V19.15.3 бойовий блок зроблено компактнішим.

## Що скорочено

Було дублювання:

```text
Сильне розкриття: Захист стрільця -2...
Після черги стрілець сильно розкрився: Захист -2...
```

Тепер лишається коротко:

```text
Розкриття: -2 Захист до наступного ходу.
```

Довгий тестовий текст:

```text
Бонус шкоди зброї / стану застосовано один раз; додаткові влучання дають тільки кубик шкоди.
```

замінено на:

```text
Бонус шкоди: 1 раз.
```

## Що не змінювалося

- шкода;
- крит;
- віддача;
- розкриття;
- укриття;
- Firebase;
- бойова панель;
- картки ворогів;
- шаблони ворогів.
