# Польовий Модуль — V19.15.11 Quick Panels Above Targets

Версія на базі V19.15.10.

## Що змінено

Панелі швидких кнопок:

```text
Дії
Інвентар
Стан персонажа
```

тепер розташовані одразу під кнопками швидких дій і над блоком `Видимі цілі`.

## Навіщо

Раніше ці панелі відкривалися під `Видимі цілі`, через що виглядало, ніби вони раптово з’являються не там, де користувач очікує.

Тепер логіка така:

```text
Швидкі дії
↓
розгорнута панель Дії / Інвентар / Стан
↓
Видимі цілі
↓
Остання дія
```

## Додано

- плавне розгортання панелей;
- плавне згортання;
- візуально панель відкривається саме від кнопок швидких дій.

## Що не змінювалося

Не змінювалися:

- бойова математика;
- віддача;
- шкода;
- крит;
- журнал;
- Firebase-структура;
- бойова панель;
- видимі цілі;
- нижня вкладка Вороги;
- шаблони ворогів.
