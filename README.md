# Польовий Модуль — V22 Enemy Target Merge Single File

V22 об’єднує «Ціль пострілу» зі вкладкою «Вороги».

## Що нового

### 1. Прибрано окремий блок «Ціль пострілу»
На екрані «Стан» більше немає окремого блоку «Ціль пострілу».

### 2. Ціль пострілу вибирається у вкладці «Вороги»
Тепер ціль обирається прямо зі списку ворогів:
- перший тап по ворогу — обирає його ціллю пострілу;
- повторний тап по вже обраному ворогу — розгортає/згортає деталі.

Обраний ворог підсвічується як ціль.

### 3. Деталі ворога залишені
Під ворогом можна розгорнути:
- позиція;
- небезпека;
- поточна дія;
- HP;
- набої;
- мораль;
- захист;
- чи обраний він ціллю.

### 4. Оточення прибрано зі «Стану»
Оточення має відображатися тільки після натискання нижньої вкладки «Оточення».

### 5. Назву очищено від декоративних символів
Із плашки «Польовий Модуль» прибрані стрілочки та зірочки.
