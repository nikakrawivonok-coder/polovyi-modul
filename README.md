# Польовий Модуль — V18.8 Weapon Damage Single File

Ця версія зроблена на основі стабільної V18.7.

## Що додано

### 1. Активна зброя персонажа

У Майстра в блоці гравця тепер можна обрати:

- зброю;
- дистанцію: здалека / зблизька.

## Доступна зброя

- ПМ
- Обріз
- Двостволка
- АКС-74У
- АК-74
- Граната

## Формули шкоди

- ПМ: d4 здалека / d4+1 зблизька
- Обріз: d4 здалека / d6+1 зблизька
- Двостволка: d4 здалека / d8 зблизька
- АКС-74У: d6 здалека / d6+1 зблизька
- АК-74: d6+1 здалека / d6+2 зблизька
- Граната: d12

## Як працює шкода

Після пострілу:

- d20 все ще перевіряє пробиття Захисту ворога;
- кожне влучання додає один кубик шкоди;
- бонус зброї додається один раз за атаку.

Приклад:

АК-74 зблизька, 2 влучання:
- шкода = 2d6+2

## Що НЕ додано в цій версії

Щоб не перевантажувати систему, у V18.8 ще НЕ додано:

- клин зброї;
- критичні влучання;
- критичні промахи;
- стани зброї;
- різні типи броні.

Це краще винести в V18.9.
