# Польовий Модуль — V13 Turn Lock Single File

V13 додає контроль ходу в бойовому режимі.

## Що нового

### Строгі ходи
Якщо активний бій і ввімкнено строгі ходи, гравець може натискати бойові дії тільки у свій хід.

Наприклад:
- активний хід `Лис` → `fox` може стріляти;
- активний хід `Ватажок` → `fox` не може стріляти;
- активний хід `Сірий` → `fox` не може стріляти.

Якщо гравець натискає дію поза ходом:
- кидок не виконується;
- набої не списуються;
- з’являється попередження;
- у GM-журнал додається службовий запис.

### Вільні дії
Майстер може перемикати режим:
- строгі ходи;
- вільні дії.

У вільному режимі гравці можуть діяти будь-коли. Це корисно для хаотичних перестрілок, засідок і сцен без суворої ініціативи.
