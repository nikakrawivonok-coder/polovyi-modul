# Польовий Модуль — V18.7 Restore Room Single File

Ця версія зроблена на основі стабільної V18.6.1.

## Що додано

### Кнопка «Відновити базову сцену»

У вкладці:

Майстер → Кімната / доступ

додано кнопку:

- Відновити базову сцену

Вона повертає стартову сцену, якщо кімната Firebase збереглася порожньою або пошкодженою після тестів.

## Що саме відновлюється

Кнопка відновлює:

- сцену «Старий блокпост»;
- стартових ворогів;
- оточення;
- бойовий стан;
- журнал сцени.

## Що НЕ видаляється

Кнопка НЕ видаляє персонажів гравців.

Тобто HP, набої, інвентар, характеристики та створені персонажі залишаються.

## Аварійна кнопка

Кнопка «Очистити кімнату Firebase» залишилась, але це повний скид кімнати.
Її краще використовувати тільки тоді, коли треба почати повністю з нуля.
