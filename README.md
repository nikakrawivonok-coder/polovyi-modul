# Польовий Модуль — V18.11.1 Player Links Hotfix Single File

Це hotfix до V18.11.

## Що виправлено

У вкладці:

Майстер → Кімната / доступ

блок «Посилання на гравців» тепер має показувати окремі кнопки для всіх персонажів кімнати.

Наприклад:

- Посилання: Лис
- Посилання: Сірий
- Посилання: Патріція

Якщо Майстер створить нового персонажа, його посилання має автоматично з’явитися у цьому списку після оновлення/рендеру.

## Що робить кожна кнопка

Кнопка копіює URL саме для відповідного персонажа:

- Лис → player=fox
- Сірий → player=grey
- Патріція → player=patricia або відповідний ID персонажа

## Що не змінювалося

Не змінювалися:

- Firebase;
- вороги;
- Оточення;
- бойова логіка;
- зброя;
- клин;
- реакції ворогів;
- відновлення базової сцени.
