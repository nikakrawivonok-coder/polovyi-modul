# Польовий Модуль — V19 Modular Base

Це технічна версія на основі стабільної **V18.12.1 Surgical Stability Fix**.

## Головне

V19 не додає нових ігрових функцій.

Мета V19 — розділити single-file `index.html` на окремі файли, щоб подальша розробка була безпечнішою.

## Структура файлів

- `index.html` — HTML-структура сторінки та підключення файлів.
- `styles.css` — усі стилі інтерфейсу.
- `app.js` — уся логіка додатку.

## Що має працювати так само, як у V18.12.1

- Firebase-синхронізація;
- Майстер / Гравець;
- кімнати;
- посилання на гравців;
- вороги;
- додавання ворогів;
- Оточення;
- Журнал;
- Видимі цілі;
- вибір цілі;
- постріли;
- зброя;
- шкода;
- крит;
- клин;
- реакції ворогів;
- відновлення базової сцени.

## Що НЕ змінювалося

Не змінювалися:

- правила гри;
- дизайн;
- бойова логіка;
- Firebase-структура;
- інтерфейс Майстра;
- інтерфейс Гравця.

## Як встановити

У GitHub Pages репозиторій потрібно завантажити всі файли з цієї папки:

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

Старий single-file `index.html` треба замінити новим `index.html`.

## Що перевірити після оновлення

1. Сторінка відкривається без білого екрану.
2. Дизайн виглядає як у V18.12.1.
3. Майстер підключається до Firebase.
4. Гравець підключається до тієї ж кімнати.
5. У Майстра працюють посилання на всіх гравців.
6. Вороги відображаються і додаються.
7. Оточення відображається.
8. Видимі цілі працюють.
9. Постріли, шкода, крит, клин працюють.
10. Відновити базову сцену працює.
