# Польовий Модуль — V18.6.1 Render Hotfix Single File

Це hotfix до V18.6.

## Що виправлено

У V18.5/V18.6 після прибирання компактного блоку «Оточення» зі вкладки «Стан» у render() залишилися звернення до неіснуючих елементів:

- sceneNameShort
- sceneDescShort

Через це JavaScript зупиняв render, і тому:

- вороги не відображалися;
- додавання ворогів у Майстра виглядало зламаним;
- вкладка «Оточення» могла виглядати порожньою;
- частина інтерфейсу не домальовувалася.

У V18.6.1 ці звернення зроблені безпечними.

## Що не змінювалося

Не змінювалися:

- логіка ворогів;
- додавання ворогів;
- шаблони ворогів;
- Firebase;
- бойова логіка;
- вибір цілі;
- вкладка «Оточення».
