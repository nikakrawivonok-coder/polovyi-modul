# Польовий Модуль — V18.6 Visible Targets Single File

Ця версія зроблена на основі стабільної V18.5.

## Що змінено

### 1. «Ціль пострілу» перейменовано на «Видимі цілі»

У вкладці «Стан» блок цілей тепер має назву:

- Видимі цілі

Це звучить природніше, бо в цьому блоці гравець не тільки обирає ціль, а й бачить усіх помітних ворогів.

### 2. Додано коротку підказку

Під списком видимих цілей додано підказку:

- 1-й тап — інформація
- 2-й тап — обрати ціллю

## Що не змінювалося

Не змінювалися:

- додавання ворогів;
- шаблони ворогів;
- нижня вкладка «Вороги»;
- вкладка «Оточення»;
- Майстерська панель;
- Firebase-синхронізація;
- логіка пострілів;
- шкода;
- вибір цілі.
