# Польовий Модуль — V20 Enemy List Restore Single File

V20 відкочує неправильну зміну ворогів із V19.

## Що виправлено

### 1. Вкладку «Вороги» повернено в нижню панель
Вороги знову відкриваються як окрема вкладка, як у попередньому вдалому варіанті.

### 2. Прибрано квадратну кнопку «Вороги» зі швидких дій
Вороги більше не займають місце серед бойових кнопок:
- Точно
- Нормально
- Черга
- Дії
- Інвентар
- Стан

### 3. Список ворогів повернено
Список ворогів знову має вигляд окремих рядків зі станом, фото/іконкою та індикатором.

### 4. Додано розгортання деталей ворога
Тепер при натисканні на ворога під ним має відкриватися невеликий блок з деталями:
- позиція;
- небезпека;
- поточна дія;
- HP;
- набої;
- мораль;
- захист.

## Збережено з V19

- чистіша назва «Польовий Модуль» без стрілок і зірочок;
- вирівнювання значків характеристик;
- toast кидків на 8 секунд;
- у Майстра показується форма тільки активного персонажа;
- блок «Посилання гравців».
