# Польовий Модуль — V19.13 Enemy Template: Автоматник

Версія на базі V19.12.1.

## Що змінено

Додано перший тестовий шаблон ворога:

```text
Автоматник
```

Шаблон розміщено не у вкладці `Майстер`, а у вкладці:

```text
Вороги
```

Блок видимий тільки Майстру.

## Що робить кнопка

У вкладці `Вороги` Майстер бачить блок шаблону й кнопку:

```text
+ Автоматник
```

Натискання додає ворога у сцену з параметрами:

```text
Назва: Автоматник
Тип: людина
Фракція: бандити
Роль: тиск вогнем, контроль простору
HP: 12/12
Захист: 12
Набої: 6
Зброя: АКС-74У
Дистанція: здалека
Стан зброї: нормальна
Мораль: середня
Лут: залишок набоїв; 1d4 додаткових набої; ніж або саморобний клинок; дріб’язок 10–40
```

## Закладені поля на майбутнє

У шаблон додано службові поля для подальшого розвитку:

```text
templateId
role
faction
behavior
lootText
imageKey
attacks
special
weakness
lastAttackType
recoilLevel
exposedUntilNextTurn
```

## Важливо

Автоматизацію віддачі черги ще не вмикали.

Правило зафіксовано в шаблоні:

```text
Черга: 3d20 -2.
Повторна черга: 3d20 -4.
Після черги: Захист -1 до наступного ходу.
Постріл 1 або 2 патронами скидає віддачу.
```

## Що не змінювалося

Не змінювалися:

- бойова логіка;
- логіка пострілів;
- шкода;
- крит;
- popup;
- нижній блок результату пострілу;
- Firebase-структура;
- бойова панель;
- журнал.
