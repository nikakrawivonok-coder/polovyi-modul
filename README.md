# Польовий Модуль — V19.16.5 Enemy Loot Draft

Версія на базі V19.16.4.

## Що додано

Перший простий цикл луту з ворога.

У картці ворога Майстра з’явився блок:

```text
Лут активному гравцю
```

Кнопки:

```text
Передати лут
Передати набої
Передати все
```

## Як це працює

### Передати лут

Додає в інвентар активного гравця предмет:

```text
Лут: <назва ворога>
```

Описом стає текст луту з картки ворога.

### Передати набої

Передає всі поточні набої ворога активному гравцю і ставить набої ворога в 0.

### Передати все

Передає і текстовий лут, і залишок набоїв.

## Важливо

Це ще не фінальна економіка предметів, а перший робочий draft:

```text
без окремого вікна підтвердження;
без вибору конкретного гравця;
без складного розбору тексту луту на окремі предмети.
```

Поки все передається активному гравцю Майстра.
