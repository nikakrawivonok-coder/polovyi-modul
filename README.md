# Польовий Модуль — V19.11.4 Actor Target Combat Routing Fix

Версія на основі V19.11.3.

## Що виправлено

### 1. Положення бойової панелі

Панель трохи опущена нижче, щоб прибрати зайвий проміжок між нею і нижньою навігацією, але не перекривати кнопки:

- Стан
- Оточення
- Вороги
- Журнал
- Майстер

### 2. Логіка “Хід → Ціль”

Кнопки пострілу більше не мають автоматично вважати, що завжди стріляє поточний гравець по першому ворогу.

Тепер для пострілу враховується бойова панель:

- `Хід` = хто стріляє;
- `Ціль` = у кого стріляють.

## Поточна підтримана логіка

Працює:

- гравець → ворог;
- ворог → гравець.

Поки заблоковано, щоб не ламати математику:

- гравець → гравець;
- ворог → ворог.

Ці два варіанти треба додавати окремо як PvP / дружній вогонь.

## Додатково

- Ворог зі станом `вибув` більше не має бути учасником бойової панелі.
- Учасник, що вибув, не може атакувати.
- Ціль, що вибула, не може бути атакована.
