# Польовий Модуль — V15 Battle Polish Single File

V15 вносить пакет покращень після тестування V14.

## Що нового

### 1. Поля введення
Збережено виправлення V14.1: поля більше не втрачають фокус після кожної літери.

### 2. Броня і ціль захисту гравця
У блоці гравців додано:
- Ціль захисту
- Броня

Атаки ворогів тепер рахують:
- ціль влучання = ціль захисту + укриття;
- броня зменшує отриману шкоду.

### 3. Фільтр журналу
У Майстра з’явились фільтри:
- Усі записи
- Публічні
- Тільки Майстру

Гравці, як і раніше, бачать тільки публічні записи.

### 4. Підтвердження небезпечних дій
Додано підтвердження для:
- очищення журналу;
- позначення ворога як «вибув».

### 5. Менш агресивне збереження
Поля сцени зберігаються кнопкою «Оновити сцену», а не після кожної літери.
