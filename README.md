# Польовий Модуль — V7 GM Key Single File

V7 додає простий ключ Майстра поверх Firebase-синхронізації.

## Що нового

- вкладка **Майстер** показується тільки якщо є правильний `gmKey`;
- посилання без ключа або з неправильним ключем відкривається як режим Гравця;
- додано службовий блок **Кімната / доступ** у вкладці Майстра;
- можна скопіювати посилання Майстра і Гравця;
- можна очистити поточну Firebase-кімнату зі стартовим станом.

## Поточний ключ Майстра

`zona-master`

## Посилання

Майстер:
`https://твій-нік.github.io/polovyi-modul/?role=gm&room=zona01&gmKey=zona-master&v=7`

Гравець:
`https://твій-нік.github.io/polovyi-modul/?role=player&room=zona01&player=fox&v=7`

## Важливо

Це домашній app-level захист, а не повна серверна безпека. Гравець без ключа не побачить вкладку Майстра, але Firebase Rules поки відкриті для тесту.

Наступний крок V8 — нормалізувати майстерську панель і зробити керування кількома гравцями/ворогами зручнішим.
