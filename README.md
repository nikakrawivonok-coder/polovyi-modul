# Польовий Модуль — V19.11.12 Popup Static Feedback Polish

Версія на основі V19.11.11.

## Що змінено

### 1. Спливаюче повідомлення ворог → гравець спрощено

Тепер popup для атаки ворога став коротким і чистим, ближчим до popup для атаки гравця:

- назва стрільця і цілі;
- великий кубик 🎲;
- рядок `Результат`;
- рядок `Ціль / Влучань`;
- рядок `Шкода / зброя / дистанція / набої`.

З popup прибрано зайве дублювання розгорнутих технічних рядків.

### 2. Нижній блок у вкладці Стан для гравця зроблено розширеним

Тепер `гравець → ворог` у статичному блоці показує детальнішу інформацію, ближчу до формату ворога:

- опис дії;
- кубик атаки;
- кидок і підсумок;
- точність;
- ціль і захист;
- шкоду і формулу;
- окремий рядок `🎲 Шкода зброї`;
- зброю / дистанцію / стан;
- реакцію ворога;
- ефекти ворога;
- залишок набоїв.

### 3. Реакції та ефекти лишаються тільки для ворогів

У розширеному блоці для `гравець → ворог` зберігаються:

- `Реакція ворога`;
- `Ефекти ворога`.

Для `ворог → гравець` цього немає, як і просили.
