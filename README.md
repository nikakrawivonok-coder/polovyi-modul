# Польовий Модуль — V8 GM Panel Single File

V8 покращує майстерську панель.

## Що нового

- Майстер бачить і редагує всіх гравців у кімнаті.
- Можна додавати нових гравців.
- Можна копіювати індивідуальні посилання гравців.
- Для кожного гравця є швидкі кнопки:
  - HP ±1
  - Втома ±1
  - Зараження ±1
  - Набої ±1
- Для ворогів додані швидкі кнопки станів:
  - Цілий
  - Поранений
  - Ледь стоїть
  - Наляканий
  - Тікає
