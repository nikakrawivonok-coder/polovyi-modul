# Польовий Модуль — V19.8 Collapsible Player Editor Sections

Версія на основі стабільної V19.7.

## Головна зміна

У вкладці **Майстер → Гравці** секції редактора активного персонажа стали згортуваними.

## Як працює

Тепер видно тільки заголовки секцій:

- Профіль;
- Бойові налаштування;
- Зброя;
- Характеристики;
- Інвентар.

Тап по заголовку секції відкриває або згортає її вміст.

## Що залишено відкритим за замовчуванням

За замовчуванням відкрита секція **Бойові налаштування**, бо вона найчастіше потрібна Майстру.

## Що не змінювалося

Не змінювалися:

- Firebase;
- бойова математика;
- вороги;
- Оточення;
- інтерфейс гравця;
- Command Core.

## Що перевірити

1. Вкладка Майстер → Гравці показує секції компактно.
2. Тап по “Профіль” розгортає / згортає профіль.
3. Тап по “Бойові налаштування” розгортає / згортає бойові поля.
4. Тап по “Зброя” розгортає / згортає зброю.
5. Тап по “Характеристики” розгортає / згортає характеристики.
6. Тап по “Інвентар” розгортає / згортає інвентарний підсумок.
7. Редагування полів працює після розгортання.
