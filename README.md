# Польовий Модуль — V19.16.7 Journal Visibility Labels Polish

Версія на базі V19.16.6.

## Що виправлено

У журналі гравця більше не показується службове слово:

```text
Публічно
```

Це слово бачить тільки Майстер.

## Що бачить гравець

Гравець бачить звичайні публічні записи без службової мітки.

Було:

```text
Публічно1 отримав лут...
```

Стало:

```text
“1” отримав лут...
```

Приватні записи гравець і далі бачить із міткою:

```text
Приватно
```

## Що бачить Майстер

Майстер бачить усі службові позначки:

```text
Публічно
Приватно
Майстру
```

## Також виправлено

Додано пробіл після службової позначки журналу через CSS.

Для записів, які починаються з імені або ID гравця, додано лапки:

```text
“1” отримав...
“Лис” забрав...
```

## Що не змінювалося

Не змінювалися:

- бойова математика;
- лут;
- вороги;
- Firebase-структура;
- вкладка Стан;
- видимі цілі;
- DATA_SCHEMA.md по суті структури.
