# Польовий Модуль — V18.5 Micro Polish Single File

Ця версія зроблена на основі стабільної V18.4.

## Що змінено

### 1. Оточення прибрано зі вкладки «Стан»
У вкладці «Стан» більше не має бути компактного блоку з оточенням.
Опис локації має відкриватися тільки через нижню вкладку «Оточення».

### 2. Повідомлення після кидка / пострілу тримається 8 секунд
Toast-повідомлення з результатом кидка, пострілу, уроном і модифікаторами тепер лишається видимим приблизно 8 секунд.

## Що не змінювалося

Не змінювалися:

- додавання ворогів;
- шаблони ворогів;
- нижня вкладка «Вороги»;
- Майстерська панель;
- Firebase-синхронізація;
- логіка пострілів;
- вибір цілі у вкладці «Стан».
