# Польовий Модуль — V19.17.8 Unified Combat Summary Text

Точкова UX-версія на базі V19.17.7.

## Що додано у V19.17.8

Короткий бойовий підсумок у вкладці `Стан` уніфіковано для двох напрямів атаки:

- гравець → ворог;
- ворог → гравець.

Новий формат показує розрахунок у природному порядку:

```text
Лис: Черга → Автоматник
Захист Автоматник: 14 (+2 через укриття)
🎲 20, 5, 18 → 15, 0, 13 (точність -5: -4 за другу чергу поспіль, -1 через ціль в укритті)
Випало: 4 на 1d4 + 1 на крит. 1d4 (кубики шкоди)
1 влуч., завдана шкода: 5. Автоматник: HP 1/8.
Залишилося набоїв: 8.
Лис розкрився: Захист Лис 12 → 10 до його наступного ходу.
```

Для гравців точні HP ворогів і далі приховані. Вони бачать стан ворога, наприклад `Автоматник: ледь стоїть.`

Для Майстра точні HP ворогів залишаються видимими.

## Що не змінювалося

- бойова математика;
- шкода;
- крити;
- віддача `-2 / -4 / -6`;
- укриття `+2` до Захисту цілі;
- додатковий `-1` до точності при стрільбі чергою по цілі в укритті;
- privacy HP ворогів для гравців;
- шаблони ворогів.
