# Польовий Модуль — V19.11.5 Combat Routing Authority Fix

Версія на основі V19.11.4.

## Що виправлено

### 1. Бойова панель стала головним джерелом правди для Майстра

Для GM-пострілів тепер використовується:

- `Хід` з бойової панелі;
- `Ціль` з бойової панелі.

Це працює навіть якщо активний гравець у старій вкладці Майстра інший.

### 2. Ворог → гравець

Виправлено пріоритет цілі для атак ворогів.

Тепер `enemyAttackTargetId()` спершу бере ціль із бойової панелі, а не зі старого select-поля `Ціль атак ворогів`.

Очікувана логіка:

- Хід: Автоматник
- Ціль: Лис
- Натиснути постріл

Результат:

- набої списуються в Автоматника;
- шкода йде Лису.

### 3. Гравець → ворог

Якщо:

- Хід: Лис
- Ціль: Автоматник

Результат:

- набої списуються в Лиса;
- шкода йде Автоматнику.

### 4. Панель опущено нижче

Панель ще трохи опущена ближче до нижньої навігації, щоб прибрати проміжок, але не перекривати кнопки.

## Поки заблоковано

- гравець → гравець;
- ворог → ворог.

Це краще реалізувати окремо як PvP / friendly fire.
