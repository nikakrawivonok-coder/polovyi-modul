# Польовий Модуль — V18.9 Weapon Condition Single File

Ця версія зроблена на основі стабільної V18.8.

## Що додано

### 1. Стан зброї

У Майстра в блоці гравця додано поле:

- Стан зброї

Доступні стани:

- добра;
- нормальна;
- зношена;
- іржава.

## Ефекти стану зброї

- Добра: без штрафів.
- Нормальна: без штрафів.
- Зношена: клинить на d20 = 1.
- Іржава: клинить на d20 = 1–2, шкода -1, мінімум 1.

### 2. Клин зброї

Якщо зброю заклинило:

- персонаж не може стріляти;
- у меню «Дії» треба натиснути «Усунути клин»;
- перевірка: 1d20 + Вправність;
- 10+ — клин усунуто.

### 3. Критичне влучання

Якщо на d20 випало 20:

- атака отримує +1 додатковий кубик шкоди за кожну 20.

Приклад:

АК-74 зблизька, 2 влучання, одна 20:
- базово 2d6+2;
- з критом 3d6+2.

### 4. Критичний промах

Якщо гравець викинув 1:

- у журналі з’являється попередження;
- Майстер може ускладнити ситуацію;
- якщо зброя зношена або іржава, можливий клин.

### 5. Вороги на d20 = 1

Якщо ворог при атаці викидає 1:

- атака вважається критичним промахом;
- ворог збивається;
- наступну атаку пропускає за рішенням Майстра.

## Що не змінювалося

Не змінювалися:

- додавання ворогів;
- Firebase;
- Оточення;
- Видимі цілі;
- вибір цілі;
- структура кімнати.
