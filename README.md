# Польовий Модуль — V19.16.1 Enemy Template Polish / Loot & Enemy Details

Версія на базі V19.16.

## Що змінено

Це точкова UX-правка вкладки `Вороги` для Майстра.

## 1. Картка ворога Майстра стала функціональнішою

У картці ворога додано:

```text
місце під майбутній портрет
HP / набої / броня / втома / зараження / віддача
лут після бою
характеристики
швидке керування HP
швидке керування набоями
показати / сховати ворога
```

## 2. Швидке керування

У вкладці `Вороги` Майстер тепер може прямо з картки ворога натискати:

```text
HP -1
HP -3
HP +1
Набої -1
Набої +1
Показати / Сховати
```

## 3. Видимість для гравця

Кнопка `Сховати` прибирає ворога з видимості гравця, але він лишається у Майстра.

## Що не змінювалося

Не змінювалися:

- бойова математика;
- віддача;
- шкода;
- крит;
- журнал;
- Firebase-структура;
- вкладка Стан;
- видимі цілі;
- шаблон Автоматника як модель розрахунків.
