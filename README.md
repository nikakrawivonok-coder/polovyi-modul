# Польовий Модуль — V19.11.8 Enemy Weapon Damage Feedback Polish

Версія на основі V19.11.7.

## Що виправлено

### 1. Шкода ворогів залежить від зброї

Раніше люди-вороги часто завдавали фіксовану шкоду `1` за влучання.

Тепер для атак `ворог → гравець` використовується зброя ворога:

- `Автоматник` / автомат / АКС-74У → шкода зброї АКС-74У;
- `Бандит з обрізом` / обріз → шкода обріза;
- `Боягуз`, звичайний бандит, пістолет → шкода ПМ;
- якщо зброя не визначена → fallback ПМ.

Формула шкоди показується у toast, журналі й статичному результаті.

### 2. Toast тримається довше

Повідомлення про постріл тепер показується приблизно 8 секунд.

### 3. Бойова панель піднята

Панель трохи піднята, щоб не заходити на нижні кнопки:

- було `bottom: 68px`;
- стало `bottom: 72px`.

## Що не змінювалося

Не змінювалися:

- логіка `Хід / Ціль`;
- списання набоїв;
- застосування шкоди;
- Firebase;
- журнал;
- player-посилання.
