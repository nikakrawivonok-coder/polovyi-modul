# Польовий Модуль — V19.6 Cleaner GM Dashboard + Handler Cleanup

Версія на основі стабільної V19.5.

## Що змінено

### 1. Панель Майстра очищено від дублювання

Прибрано великі поля:

- `Гравець`
- `Ворог / ціль`

Вони дублювали міні-картки гравців і ворогів.

Замість них додано компактний рядок:

- Активний: ім’я активного гравця;
- Ціль: ім’я активного ворога.

### 2. Вибір лишився через міні-картки

- тап по міні-картці гравця → активний гравець;
- тап по міні-картці ворога → активна ціль.

### 3. Очищено старі службові обробники

Перевірено й прибрано залишок старої логіки `data-player-quick`, яка залишалася після видалення дубльованих кнопок:

- `+1 HP`
- `−1 HP`
- `−1 Втома`
- `+1 Втома`

## Що не змінювалося

Не змінювалися:

- Firebase;
- бойова математика;
- зброя;
- клин;
- Оточення;
- інтерфейс гравця;
- структура даних кімнати.

## Що перевірити

1. У Панелі Майстра більше немає великих полів “Гравець” і “Ворог / ціль”.
2. Є компактний рядок “Активний / Ціль”.
3. Тап по міні-картці гравця змінює активного гравця.
4. Тап по міні-картці ворога змінює активну ціль.
5. Керування активним гравцем працює.
6. Керування активним ворогом працює.
7. Швидкий запис і ускладнення працюють.
