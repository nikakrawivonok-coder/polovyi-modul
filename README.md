# Польовий Модуль — V19.2 Master Control Dashboard

Версія на основі стабільної V19.1.

## Що додано

- Міні-картки гравців: ім’я, HP, Захист, набої. Тап по картці робить гравця активним.
- Міні-картки ворогів: ім’я, стан, Захист, ефекти. Тап по картці робить ворога активною ціллю.
- Швидкий запис у журнал гравців або як нотатку Майстра.
- Швидке ускладнення: аномальний гул, хтось наближається, технічний збій, фланговий маневр, тиша перед ривком.

## Що не змінювалося

Не змінювалися Firebase, бойова математика, зброя, клин, реакції ворогів, Оточення, структура даних кімнати.
