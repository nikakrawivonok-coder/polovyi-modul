# Польовий Модуль — V19.15.2 Public Journal Ammo Privacy Fix

Версія на базі V19.15.1.

## Що виправлено

У V19.15 і V19.15.1 було приховано набої ворогів у частині інтерфейсу, але лишився витік у публічному журналі:

```text
Набої ворога: 6
```

Причина: якщо атаку ворога виконував Майстер, код додавав набої ворога в загальний текст результату, а потім цей текст записувався як `public`.

## Тепер

### Публічний журнал

Не містить кількість набоїв ворога.

### GM-журнал

Містить окремий службовий запис:

```text
Автоматник: після атаки лишилось набоїв: 6.
```

## Також виправлено

Для черги прибрано дублювання старого тексту:

```text
Після атаки ворог розкрився: Захист -1
```

Бо фінальне правило черги вже таке:

```text
Після черги стрілець сильно розкрився: Захист -2 до наступного ходу.
```

## Що не змінювалося

Не змінювалися:

- бойова математика;
- шкода;
- крит;
- Firebase;
- бойова панель;
- картки ворогів;
- шаблони ворогів.
