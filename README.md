# Польовий Модуль — V19.11.14 Static Shot Result Exact Format

Точкова версія після V19.11.13.

## Що змінено

Змінено тільки нижній інформативний блок у вкладці `Стан` після пострілу.

Popup / спливаюче повідомлення після пострілу не чіпалося.

## Новий формат нижнього блоку

### Гравець → ворог

Формат:

```text
Лис: Точний постріл → Боягуз
🎲 15 (+2 від точності пострілу)
Захист цілі: “Боягуз” 12 пробитий
Шкода зброї: 3 (ПМ · здалека · 1d4)
“Боягуз” тепер має 5/8 HP.
У “Лис” лишилось набоїв: 8.
Реакція ворога: пішов в укриття.
Ефекти ворога: в укритті.
```

### Ворог → гравець

Формат:

```text
Автоматник: Точний постріл → Лис
🎲 10 (+2 від точності пострілу)
Захист цілі: “Лис” 12 пробитий
Шкода зброї: 4 (АКС-74У · здалека · 1d6)
“Лис” тепер має 0/10 HP.
У “Автоматник” лишилось набоїв: 1.
```

## Важливо

Реакція ворога та ефекти ворога показуються тільки при `гравець → ворог`.

Для `ворог → гравець` вони не показуються.

## Що не змінювалося

Не змінювалися:

- popup / спливаюче повідомлення;
- логіка `Хід / Ціль`;
- розрахунок шкоди;
- крит;
- списання набоїв;
- Firebase;
- журнал;
- посилання гравців;
- бойова панель;
- інші частини інтерфейсу.
