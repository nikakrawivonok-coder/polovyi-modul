# Польовий Модуль — V19.15.9 Merge Enemies Into Visible Targets

Версія на базі V19.15.8.

## Що змінено

У вкладці `Стан` прибрано окремий дубльований блок `Вороги`.

Тепер у `Стані` лишається:

```text
персонаж
швидкі дії
видимі цілі
остання дія
```

## Видимі цілі стали інформативнішими

Іконки/статусні значки ворогів, які раніше були в окремому блоці `Вороги`, перенесено прямо в картки `Видимі цілі`.

Наприклад:

```text
☠ Автоматник    !
ледь стоїть · Захист 11
```

```text
☠ Бандит з обрізом    ✚
поранений · Захист 12
```

```text
☠ Боягуз    )))
наляканий · Захист 12
```

## Що залишилось без змін

Нижня вкладка `Вороги` лишається основним місцем для повного списку та майбутнього керування ворогами.

Не змінювалися:

- бойова математика;
- віддача;
- шкода;
- крит;
- журнал;
- Firebase-структура;
- бойова панель;
- шаблони ворогів.
