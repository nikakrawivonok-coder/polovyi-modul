# Польовий Модуль — V18.1 Enemy Tap Target Single File

Ця версія зроблена строго на основі оригінальної стабільної V18.

## Що додано

### Вибір цілі через вкладку «Вороги»

У нижній вкладці «Вороги»:

- перший тап по ворогу обирає його ціллю пострілу;
- повторний тап по вже обраному ворогу розгортає або згортає деталі;
- обрана ціль підсвічується;
- постріли «Точно / Нормально / Черга» йдуть по обраній цілі.

### Деталі ворога

При повторному тапі по обраному ворогу показується:

- позиція;
- небезпека;
- поточна дія;
- HP;
- набої;
- мораль;
- захист;
- статус цілі.

## Що НЕ змінювалося

Щоб не зламати стабільну V18, у цій версії НЕ змінювалися:

- додавання ворогів;
- шаблони ворогів;
- вкладка «Оточення»;
- Майстерська панель;
- Firebase-синхронізація;
- блок «Ціль пострілу» на вкладці «Стан».
