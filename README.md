# Польовий Модуль — V19.12 Final Combat UI Polish

Версія на базі V19.11.15 STABLE.

## Головна мета

Поліпшити зручність бойової панелі Майстра без зміни стабільної бойової логіки.

## Що змінено

### 1. Кнопка початку / наступного ходу стала зрозумілішою

Було:

```text
▶
```

Стало:

```text
▶
Почати
```

або під час бою:

```text
▶
Далі
```

### 2. У блоці Хід / Ціль додано короткий стан

Для активного учасника й цілі тепер показується компактна інформація:

- для гравця: `HP / набої`;
- для ворога: `стан / HP`.

### 3. У чипах учасників додано компактні підписи

У горизонтальному списку бойової панелі тепер видно не тільки ім’я, а й короткий стан:

- гравець: `HP · набої`;
- ворог: `стан · HP`.

### 4. Активний учасник і ціль позначені чіткіше

- активний хід отримує позначку `Х`;
- ціль отримує позначку `Ц`.

## Що не змінювалося

Не змінювалися:

- логіка пострілів;
- `Хід / Ціль`;
- розрахунок шкоди;
- крит;
- списання набоїв;
- нижній блок результату пострілу;
- popup після пострілу;
- Firebase;
- журнал;
- посилання гравців;
- шаблони ворогів.
