# Польовий Модуль — V19.11.11 Enemy Crit Dice Result Polish

Версія на основі V19.11.10.

## Що виправлено

### 1. Бойова панель піднята ще трохи вище

Панель усе ще трохи заходила на нижні кнопки.  
Тепер її піднято:

- було `bottom: 76px`;
- стало `bottom: 80px`.

### 2. Атака ворога має великий кубик у результаті

Для `ворог → гравець` toast тепер ближчий до формату `гравець → ворог`:

- великий значок 🎲;
- поруч/після нього значення основного кидка d20;
- нижче — повна інформація про влучання, шкоду, зброю, HP і набої.

### 3. Критичне влучання ворога

Якщо у ворога на d20 випадає 20, тепер це рахується як крит:

- додається додатковий кубик шкоди;
- у повідомленні показується `Крит: +1 кубик`;
- формула шкоди враховує додатковий кубик так само, як у гравця.

### 4. Набої стрільця

У повідомленні та статичному результаті для атаки ворога чітко показується:

- `Набої стрільця: X`.
