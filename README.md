# Польовий Модуль — V19.3 Enemy Control Dashboard

Версія на основі стабільної V19.2.

## Головна зміна

У верхній Панелі Майстра додано повноцінний блок керування активним ворогом.

## Що тепер можна змінювати без скролу вниз

Для активного ворога:

- HP до одиниці;
- Max HP;
- Захист;
- Набої;
- Стан;
- Мораль;
- Поточна дія;
- Видимість;
- Укриття;
- Пригнічення;
- Паніку;
- швидко встановити: поранений / ледь стоїть / вибув.

## Як користуватися

1. У Панелі Майстра обери ворога у списку або тапни по міні-картці ворога.
2. Нижче відкриється блок “Активний ворог”.
3. Змінюй HP, Захист, набої кнопками -/+.
4. Стан, мораль і поточну дію можна редагувати прямо в цьому блоці.

## Що не змінювалося

Не змінювалися:

- Firebase;
- бойова математика;
- зброя;
- клин;
- Оточення;
- структура даних кімнати;
- інтерфейс гравця.
