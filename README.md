# Польовий Модуль — V18.4 State Enemy Tap Flow Single File

Ця версія зроблена строго на основі оригінальної стабільної V18.

## Що додано

### Вороги у вкладці «Стан» стали інтерактивними

У першій вкладці «Стан», у блоці «Ціль пострілу»:

- 1-й тап по ворогу — розгортає інформацію під цим ворогом;
- 2-й тап по цьому ж відкритому ворогу — обирає його активною ціллю пострілу.

## Що показується у розгорнутій інформації

- стан;
- позиція;
- небезпека;
- що робить;
- HP;
- набої;
- мораль.

## Що не змінювалося

Не змінювалися:

- нижня вкладка «Вороги»;
- додавання ворогів;
- шаблони ворогів;
- вкладка «Оточення»;
- Майстерська панель;
- Firebase-синхронізація;
- логіка пострілів.
