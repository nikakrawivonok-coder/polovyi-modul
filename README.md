# Польовий Модуль — V19.15.7 Recoil Reset & Newline Fix

Версія на базі V19.15.6.

## Що виправлено

### 1. Символи `\n` у блоці “Остання дія”

У короткому підсумку вкладки `Стан` показувалися буквальні символи:

```text
\n
```

Тепер це нормальні переноси рядків.

### 2. Перша черга могла стати “2-а черга, -4”

Причина: якщо `Бій не активний`, але в кімнаті/Firebase залишився старий `recoilLevel` після попередніх тестів, перший новий постріл чергою міг брати стару віддачу.

Тепер:

```text
якщо бій не активний — черга не тягне стару віддачу;
перша черга поза активним боєм = -2;
при старті бою recoil/exposed стан скидається для гравців і ворогів.
```

## Правильна логіка

```text
1-а черга: -2
2-а черга: -4
3-я черга: -6
4-а черга: -8
```

Укриття додається окремо:

```text
Укриття: ще -1 до черги.
```
