# Польовий Модуль — V19 Interface Cleanup Single File

V19 прибирає зайве з головного екрана і робить вкладки компактнішими.

## Що нового

### 1. Вирівняні значки характеристик
Значки біля Захисту, Здоров’я, Втоми, Зараження і Набоїв вирівняні по одній вертикальній лінії.

### 2. Чистіша назва
З плашки «Польовий Модуль» прибрані декоративні стрілки та зірочки.

### 3. Вкладку «Вороги» прибрано з нижньої панелі
Вороги тепер відкриваються на екрані «Стан» через розгортну кнопку «Вороги», як «Дії», «Інвентар» і «Стан».

### 4. Оточення показується лише у вкладці «Оточення»
Міні-блок оточення більше не займає місце на екрані «Стан».

### 5. Toast кидків тримається 8 секунд
Спливаюче повідомлення з кубиками, уроном і результатом тепер не зникає так швидко.

### 6. Майстер бачить параметри лише активного персонажа
У вкладці «Майстер → Гравці» показується форма тільки активного персонажа. Перемикання між гравцями лишилося зверху.

### 7. Посилання для всіх гравців
У блоці «Гравці» додано розгортний блок «Посилання гравців», де можна скопіювати посилання для кожного персонажа, зокрема нового персонажа на кшталт «Патріція».
