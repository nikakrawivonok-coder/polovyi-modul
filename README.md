# Польовий Модуль — V19.17.12 Journal Legacy Cleanup Checkpoint

Точковий cleanup-патч на стабільній базі V19.17.10.

## Що зафіксовано як стабільне

- 1 патрон не знижує Захист стрільця.
- 2 патрони знижують Захист на 1 тільки при 0 влучань.
- 3 патрони / черга знижує Захист на 2 після кожної черги.
- Віддача черги прогресує: `-2 / -4 / -6`.
- Гравець бачить Захист цілі та пояснення модифікаторів Захисту.
- Гравець не бачить точні HP ворогів.
- Майстер бачить точні HP ворогів.

## Що змінено у V19.17.12

- Бойові записи в Журналі тепер беруться з того самого role-aware короткого підсумку, що й вкладка `Стан`.
- Публічний бойовий запис не має відкривати гравцю точні HP ворога.
- Для Майстра додається окремий GM-запис `Деталі Майстра`, якщо він відрізняється від публічної версії.
- Залишено показ Захисту цілі для гравців і Майстра, включно з поясненням типу `(+2 через укриття)`.

## Що не змінювалося

- Бойова математика.
- Формула шкоди.
- Критична шкода.
- Укриття.
- Віддача.
