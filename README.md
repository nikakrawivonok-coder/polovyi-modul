# Польовий Модуль — V9 Scene Tools Single File

V9 додає майстерські інструменти для сцен, ворогів і луту.

## Що нового

### Шаблони сцен
- Старий блокпост
- Поле аномалій
- Підвал під блокпостом
- Стоянка бандитів

Шаблон оновлює опис сцени, звуки, запахи, об’єкти і стартових ворогів.

### Шаблони ворогів
- Боягуз
- Бандит
- Бандит з обрізом
- Автоматник
- Ватажок

### Лут / знахідки
- Набої
- Медичне
- Хабар / мотлох
- Дивна знахідка
- Кастомний предмет поточному гравцю
