# Польовий Модуль — V19.8.2 Player Editor Collapse Fix

Версія на основі V19.8.1.

## Що виправлено

У V19.8 секції у вкладці `Майстер → Гравці` виглядали як зайві сірі клавіші, а частина полів фактично залишалася видимою як раніше.

У V19.8.2 виправлено:

- заголовки секцій тепер не виглядають як світлі кнопки;
- усі секції за замовчуванням згорнуті;
- поля `HP / Макс. HP / Втома / Зараження / Набої / Броня / Захист / Макс. захист` знаходяться всередині секції `Бойові налаштування`;
- поля `Зброя / Дистанція / Стан зброї / Клин` знаходяться всередині секції `Зброя`;
- характеристики знаходяться всередині секції `Характеристики`;
- тап по заголовку секції розгортає / згортає її.

## Що не змінювалося

Не змінювалися Firebase, бойова математика, вороги, Оточення, інтерфейс гравця, Command Core.
