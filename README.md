# Польовий Модуль — V19.4 Player Control Dashboard

Версія на основі стабільної V19.3.

## Головна зміна

У верхній Панелі Майстра додано компактний блок керування активним гравцем.

## Що тепер можна змінювати без скролу вниз

Для активного гравця:

- HP;
- Max HP;
- Захист;
- Max Захист;
- Втома;
- Зараження;
- Набої.

## Швидкі кнопки

- +1 HP;
- -1 HP;
- -1 Втома;
- +1 Втома.

## Як користуватися

1. Відкрий вкладку «Майстер».
2. Тапни по сірій міні-картці гравця або вибери його у полі «Гравець».
3. Під списком гравців з’явиться блок «Активний гравець».
4. Змінюй показники кнопками -/+.

## Що не змінювалося

Не змінювалися:

- Firebase;
- бойова математика;
- зброя;
- клин;
- вороги;
- Оточення;
- структура даних кімнати;
- інтерфейс гравця.
